# Практическая работа №34. Управление состоянием: Pinia

Простая корзина товаров на Vue 3 + Pinia + Vue Router.

## Структура

```
src/
  stores/
    cart.js        - хранилище корзины: state, getters, actions, localStorage, лимит, отмена
    favorites.js   - второе хранилище: избранные товары
  pages/
    CatalogPage.vue - каталог: «В корзину» и сердечко «в избранное»
    CartPage.vue    - корзина: количество, сумма, +/-/✕, очистка, «Скачать корзину»
  router/
    index.js       - маршруты / и /cart
  App.vue          - шапка (ссылки, «Отменить», счётчик избранного), предупреждение, RouterView
  main.js          - подключение Pinia и роутера
```

## Что сделано

- Pinia подключена в `main.js` через `app.use(pinia)`
- Store корзины по примеру: `state` (items), `getters` (count, sum), `actions` (addToCart, removeFromCart, clearCart, updateQuantity)
- Все изменения корзины - только через actions, компоненты их просто вызывают
- Корзина и избранное сохраняются в `localStorage` и не пропадают после перезагрузки
- Типизация: типы `CartItem`, `CartState`, `FavoritesState` и параметры actions описаны через JSDoc

### Продолжение

1. **Лимит корзины** - не больше 10 товаров суммарно. При попытке добавить 11-й (или нажать «+») появляется предупреждение, товар не добавляется
2. **Избранное** - второй store `favorites.js`, счётчик «♥ Избранное: N» в шапке обновляется сам
3. **Отмена последнего действия** - перед каждым изменением store сохраняет копию корзины в `history`, кнопка «Отменить» возвращает последнюю копию (работает для добавления, удаления, изменения количества и очистки)
4. **Экспорт в JSON** - кнопка «Скачать корзину» скачивает файл `cart.json` (`JSON.stringify` + `Blob` + ссылка `<a download>`)

## Что проверить

1. Добавить товары в каталоге - в шапке меняется «Корзина (N)»
2. Добавить 11-й товар - появляется предупреждение, счётчик остаётся 10
3. Нажать на сердечки - меняется «Избранное» в шапке
4. В корзине нажать «-», «✕» или «Очистить», затем «Отменить» - корзина возвращается как была
5. «Скачать корзину» - скачивается `cart.json`
6. Обновить страницу (F5) - корзина и избранное на месте
